## 👋 About Me / 关于我

> 把“能运行”继续打磨成“好用、清晰、可维护”的产品。

- 🎓 来自天津的学生开发者，关注桌面工具、全栈应用与真实的产品体验
- 🦀 正在深入 `Rust`、`Tauri v2`，探索更现代的跨平台桌面开发
- 🌐 使用 `Vue`、`Spring Boot`、`FastAPI` 构建完整的全栈应用
- 🤖 对多 Agent 应用、智能学习工具和工程化落地保持长期兴趣
